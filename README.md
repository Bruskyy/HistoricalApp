# HistoricalApp

Aplicativo educacional gamificado para ensino de História — "o Duolingo do conhecimento histórico".

## Status

Projeto em fase de **pesquisa e planejamento** (pré-desenvolvimento). Nenhum código de produto foi escrito ainda; o objetivo desta fase é validar oportunidade de mercado e definir escopo antes de programar.
